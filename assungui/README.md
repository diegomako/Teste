# Complexo Assungui – Rede coletora 138 kV × 34,5 kV

- `simulador_138kV_assungui.html`: simulador interativo de payback. O preço da energia (R$/MWh), o fator de perdas e os custos de CAPEX são editáveis.
- `racional_138kV_assungui_1pagina.html`: resumo estático em 1 página A4, a R$ 400/MWh.

Fontes: Memorial Descritivo MD.ASI.00 e planilha "Análise Custos x Perdas".
Abra os arquivos em qualquer navegador; não é preciso internet.
